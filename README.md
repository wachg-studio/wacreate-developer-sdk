# 机械动力·蛙创studio 开发者生态仓库

这是机械动力·蛙创studio 面向附属包开发者发布的公共开发仓库。仓库的目标是让开发者在不接触主包内部实现的情况下，使用稳定 API、MCP 工具、示例代码和精选资源制作自己的机械动力扩展。

## 这个仓库适合谁

适合希望制作以下内容的开发者和 AI 编程代理：

- 电力、蒸汽、航空、物流、加工和自动化等机械附属包；
- 使用机械网络的动力源、传动节点和耗能机器；
- 带物品、流体、库存、配方或多方块逻辑的机器；
- 需要主包动画、护目镜信息和依赖提示的附属包；
- 需要通过 MCP 自动生成模板、动画、模型检查和资源注册的开发流程。

## 发布内容

### MCP 工具

`mcp/wacreate-mcp.exe` 是 Windows 单文件 MCP 服务。它可以由支持 stdio 的 MCP 客户端启动，提供：

- 公共 API 目录查询；
- 附属包缺失主包提示生成；
- 通用机械扩展合同校验；
- 机械附属包骨架生成；
- 六向齿轮箱模板生成；
- 模型盒体和 UV 重叠检查；
- 机械骨骼动画生成和注册桥接；
- 精选开发贴图安装与纹理注册。

MCP 的源码位于 `mcp/tools/`，开发文档位于 `mcp/tools/WACREATE_MCP_CN.md`。MCP 只生成文件和调用公开合同，不执行附属包代码，也不读取主包私有源码。

### 公开 SDK

`sdk/` 是附属包开发者可阅读和引用的公开 SDK：

- `sdk/wacreate_sdk/public_api.py`：API 版本、公共方法名、登记辅助和缺失主包提示辅助；
- `sdk/examples/`：机械节点和视觉规格的最小注册示例；
- `sdk/assets/models/`：传动杆、大小齿轮和齿轮箱的精选模型模板；
- `sdk/assets/textures/`：与模板配套的精选开发贴图；
- `sdk/docs/`：公共 API 和资源使用边界。

附属包应使用自己的命名空间、自己的配方、自己的品牌和自己的运行时逻辑，并声明依赖机械动力·蛙创studio 主包。

### ZIP 测试包

`wacreate-test-pack.zip` 是一个可导入 MC Studio 的最小测试包，用来验证：

1. 主包依赖是否正确加载；
2. 附属包缺失提示是否能够工作；
3. `RegisterAddon` 是否能登记附属包；
4. `RegisterMechanicalComponent` 是否能注册一个最小动力节点；
5. 行为包和资源包的目录、清单和命名空间是否正确。

测试包只保留一个公共 API 测试机、一个基础模型、一张贴图和最小注册桥接。它不包含完整机械网络，也不能脱离主包独立运行。

## 主包依赖

附属包需要安装并启用机械动力·蛙创studio 主包，当前公共 API 版本为 v1，最低示例版本为 `0.0.31`。主包负责机械网络、流体网络、物流、持久化、性能调度、完整机器逻辑和官方运行时；附属包负责自己的玩法内容。

## 明确不公开的内容

下列内容不会进入这个开发者仓库：

- 主包完整服务端和客户端源码；
- 机械网络、流体网络、物流和存档恢复的核心实现；
- 性能调度、兼容层和内部数据结构；
- 完整官方模型、动画、材质和 UI；
- 独家算法、服务器配置、密钥和部署信息；
- 可绕过主包依赖的独立运行时。

公开 SDK 中的模型和贴图是精选开发模板，不是主包完整资源导出。发布附属包时应重新制作或检查自己的模型、UV、动画和材质。

## 使用边界

推荐开发流程是：先查询 API 目录，再创建机械合同，之后生成附属包骨架，补齐自己的方块和资源，运行静态校验，最后在游戏内测试加载、区块重载、动力拓扑、动画方向和设备性能。

通过 MCP 或静态校验不代表已经完成网易游戏内验证。附属包仍需要自行处理版本兼容、异常状态、性能预算和玩家可见错误提示。
