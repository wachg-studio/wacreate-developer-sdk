# 资源使用边界（精选模板怎么用）

`sdk/assets/` 里的模型和贴图是官方挑选的**开发参考模板**，帮你省去从空白开始的成本。它们不是主包完整资源导出，也不代表你获得了官方美术的完整授权。

## ✅ 允许

- 在依赖《机械动力·蛙创studio》主包的附属包中引用或修改这些模板；
- 开发时对照模板检查自己的 UV、盒体尺寸和动画朝向；
- 修改后的模板资源随你的附属包一并分发。

## 🚫 不允许

- 原样照搬模板资源并宣称原创，或单独售卖、再分发这些文件；
- 把模板当作主包完整资源使用，或暗示拥有官方美术授权；
- 复制未列入本目录的官方资源、动画、UI 和材质。

## 📋 发布附属包前，请逐项检查

1. 模型使用了你自己的命名空间（namespace），不与主包或其他附属包冲突；
2. UV 无重叠，盒体尺寸和朝向符合你自己的方块逻辑；
3. 贴图经过重制或显著修改，配色和品牌属于你自己；
4. 保留主包依赖提示，没有移除或绕过依赖检查。

拿不准的用法，先到开发者交流群（`1125647293`）或 <https://wachg.xyz/create/suggest/> 确认，再发布。
